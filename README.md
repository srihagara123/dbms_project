📖 About the Project
Apex Bank Management System is a modern, interactive banking interface developed as a Database Management System (DBMS) project by Group C4, Department of Computer Science and Engineering, Amrita School of Computing, Amritapuri Campus.
The application presents a simulated banking environment where users can explore banking operations, role-based dashboards, transaction workflows, audit trails, and database administration features through an intuitive, dark-themed interface.
The project connects theoretical DBMS concepts with a practical user interface, demonstrating how relational banking systems can organize financial information, manage access permissions, and represent transaction processing workflows.
Note: This project currently presents simulated database operations through its frontend. Actual database persistence, database-level security, and transaction guarantees depend on the implementation of a connected backend.
🎯 Project Objectives
•	Demonstrate the application of relational database management concepts in a banking environment.
•	Illustrate transaction workflows using ACID principles.
•	Demonstrate role-based access control (RBAC) through role-specific interfaces.
•	Represent banking operations such as deposits, withdrawals, transfers, and loan calculations.
•	Visualize audit trails, database administration, and system monitoring.
•	Build a responsive and user-friendly interface for exploring banking workflows.

🖥️ Getting Started
Follow these steps to run the project locally.
Prerequisites
•	Node.js (version 18 or later recommended)
•	npm
•	Git
Installation
1. Clone the repository P git clone https://github.com/srihagara123/dbms_project

**2. Navigate to the project directory**

cd DBMS-UI-DESIGN
 
3. Install dependencies
npm install

**4. Start the development server**

npm run dev
 
5. Open the application
Visit the local URL displayed in your terminal. The default Vite development URL is usually:
http://localhost:5173
